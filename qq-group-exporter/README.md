# QQ群成员导出工具

使用 **NapCat.Shell**（基于 NTQQ）提供 OneBot v11 HTTP API，Python Flask Web 程序连接 API 实现群成员批量导出及参团率统计。

## 功能特性

- Web 界面操作，无需命令行
- 群列表按创建时间倒序展示
- 显示群头像、名称、成员数、群主头像及昵称
- 超过 5 个群自动分页
- 一键导出群成员名单为 Excel
- 按入群时间正序排列
- **参团率统计**：自定义时间跨度，选择主群和多位扫者（群主），统计每位主群成员在各扫者群中的出现次数，汇总导出 Excel

## 快速开始

### 第一步：下载 NapCat.Shell

1. 访问 https://github.com/NapNeko/NapCatQQ/releases
2. 下载最新版 `NapCat.Shell.zip`
3. 解压到任意目录（如 `D:\NapCat.Shell\`）
4. 运行 `NapCat.Shell.exe`，扫码登录 QQ

### 第二步：配置 HTTP API

1. 浏览器打开 NapCat WebUI：http://127.0.0.1:6099
2. 输入 token 登录（token 在 `config/webui.json` 中查看）
3. 进入 **OneBot11 配置** → **HTTP 服务**
4. 添加 HTTP 服务器：
   - 主机：`0.0.0.0`
   - 端口：`8081`
   - 启用：√
   - 其余默认
5. 保存配置，重启 NapCat.Shell

### 第三步：运行 Python 程序

双击 `启动.bat`，或手动运行：

```bash
pip install flask flask-cors openpyxl requests
python web_exporter.py
```

### 第四步：使用

打开浏览器访问 http://127.0.0.1:8080

## 常见问题

### 连接不上 NapCat / 提示"未连接到 OneBot API"

如果 NapCat 已经正常运行并能收发消息，但本工具提示连接不上，请按以下步骤排查：

#### 1. 验证 API 是否通

打开命令行（CMD 或 PowerShell），执行：

```bash
curl http://127.0.0.1:8081/get_login_info
```

可能的结果：

| 返回结果 | 原因 | 解决方法 |
|----------|------|----------|
| `curl: (7) Failed to connect` | HTTP API 未启动或端口不对 | 检查 NapCat 的 OneBot11 HTTP 服务是否启用、端口是否为 8081 |
| `{"message":"token verify failed!"}` | 开启了访问令牌验证 | 见下方「token 验证失败」 |
| `{"retcode":0,...}` | API 正常，问题在别处 | 检查 `ONEBOT_URL` 环境变量是否被修改 |

#### 2. token 验证失败

NapCat 的 OneBot11 HTTP 服务默认可能配置了访问令牌（access token），未携带 token 的请求会被拒绝。

**解决方法：关闭 token 验证**
1. 打开 NapCat WebUI：http://127.0.0.1:6099
2. 进入 **OneBot11 配置** → **HTTP 服务**
3. 找到你的 HTTP 服务器配置，把 `token`（或访问令牌）字段清空
4. 保存配置，重启 NapCat.Shell

## 参团率统计

在首页点击「参团率统计」进入统计页面。

### 使用步骤

1. **选择时间跨度**：设置起止日期，扫者群的创建时间需在该范围内
2. **选择主群**：从你是群主或管理员的群中选一个。主群的普通成员为统计对象（已排除群主和管理员），主群群主自动作为扫者，主群不受时间范围限制、强制参与统计
3. **排除水群**（可选）：搜索并添加要排除的群，这些群不参与统计
4. **自选群**（可选）：搜索并添加群，这些群的群主自动作为扫者，且自选群不受时间范围限制、强制参与统计
5. **选择扫者（好友）**：从好友列表中搜索并选择多位扫者（群主）
6. **选择扫者（团书群）**：搜索群名，选中群后将该群群主作为扫者加入
7. **黑群选择**（可选）：搜索并添加黑群，黑群的全部成员从统计名单中排除
8. **工作人员**（可选）：从好友中选择工作人员，从统计名单中排除
9. **点击「导出名单」**：生成统计 Excel

> 主群群主、自选群群主、好友扫者、团书群扫者会自动合并去重，共同参与统计。
>
> 统计用户池 = 主群普通成员 - 黑群全部成员 - 工作人员

### 统计 Excel 格式

**左侧 - 参团数据：**

| 列名 | 说明 |
|------|------|
| QQ号 | 主群成员QQ号 |
| 昵称 | 主群成员昵称 |
| 总参团次数 | 所有扫者群中出现次数之和 |
| 扫者A / 扫者B / ... | 每位扫者一列，统计该成员在该扫者为群主的群中的出现次数 |

**右侧 - 团书群对照表（空一列后）：**

| 列名 | 说明 |
|------|------|
| 扫者ID | 群主昵称 |
| 团书群 | 群名称 |
| 人数 | 群成员数 |
| 建群日期 | 群创建日期 |

团书群按建群日期正序排列。数据按总参团次数倒序排列，首行冻结。

文件名格式：`参团率统计（起始日期-结束日期）-主群名.xlsx`
